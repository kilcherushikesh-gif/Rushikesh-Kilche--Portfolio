Fitbit Activity & Wellness Analysis

Python · pandas · SQLite · SQL · Streamlit

Business Question

How do daily activity patterns relate to sleep, and how complete are the wearable logs?

Data & Preparation

Combined Fitbit activity, sleep, heart-rate, and weight logs in SQLite. Removed 72 zero-step, full-day sedentary non-wear records, dropped 3 duplicate sleep rows, standardized timestamps, and rolled roughly 2.4 million heart-rate readings up to hourly values.

Analysis

SQL explores weekday and hourly activity, user activity segments, sleep-duration groups, nights under 7 hours, heart-rate patterns, and data coverage. The Streamlit app exposes cleaning, dashboard, and query views.

What the data supports

Weight and heart-rate coverage is limited: only 8 users logged weight and 14 users have heart-rate records in the source dataset. Treat comparisons involving those measures as directional, not representative of every participant.

Stock Market SQL Analysis

SQL · SQLite · Python · Streamlit

Business Question

What do historical prices and simple moving-average signals reveal across six NSE stocks?

Data & Preparation

Loaded six stock price histories covering 2015-01-01 to 2018-07-31, with 889 trading-day rows per stock. Built a SQLite database and a 17-task SQL analysis playground.

Analysis & Findings

Used moving averages, LAG, returns, and signal comparisons. Raw close-to-close returns misread 1:1 bonus adjustments as sharp losses: Infosys showed -49.9% on 2015-06-15 and TCS -50.4% on 2018-05-31. After adjustment, the project reports period returns of +38.2% for Infosys and +52.4% for TCS, instead of raw -30.9% and -23.8%.

Interpretation

Corporate actions need to be accounted for before comparing historical returns. Moving-average signals are an educational backtest; the analysis excludes transaction costs and does not establish future performance.

Cricbuzz LiveStats

Python · Streamlit · SQLite · SQL · Plotly

Business Question

How can match and player records be explored together in one interactive cricket analytics app?

Data & Preparation

Parsed Cricsheet YAML into SQLite and connected live/recent match and player views to the Cricbuzz API. The project README reports 4,577 matches, 5,059 players, 223 teams, 388 venues, 1,770,801 runs, and 65,846 wickets in its database.

Analysis & Product

Built searchable dashboards, visual summaries, 25 SQL analysis queries, and database CRUD tools. The app combines historical ball-by-ball exploration with API-powered match views.

Limitations

Historical coverage depends on the available Cricsheet files; live views depend on the external API and its availability.
